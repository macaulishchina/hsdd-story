# HSDD Story v1

状态：完成

交付目标：完成本地开发方向图，让人和 AI 通过网页与 MCP 读写同一份项目 XML。

## 交付

- Python 3.12 本地服务、三个 MCP 工具、方向图网页、配套 Skill、示例及自动化测试。
- 网页和 MCP 共用存储。结构修改原子保存，版本与文件快照用于识别冲突。
- 业务项目使用 .hsdd/story.xml。演示使用独立的 .demo 工作区。

## 决定

- D1：使用 Python、MCP SDK、Starlette 与 Uvicorn，避免为一个本地项目运行多套服务。
- D2：网页以固定格式展示节点，人保存独立输入。工程状态由 AI 核对并写回。
- D3：使用 Streamable HTTP 连接本机 MCP。客户端连接与 Skill 安装按项目选择。

## 验证

- P1 完成：XML 校验、三维状态、分层读取、修改与归档。
- P2 完成：网页、MCP、CLI 与 Skill。Skill 格式验证通过。
- P3 完成：Windows 上 14 项自动化测试通过，包括使用 MCP SDK 的 HTTP 集成测试。
- Chrome 通过总览、子图、并行节点、证据展开、版本冲突、保留草稿、MCP 读回和小屏布局验证。
- wheel 在隔离目录安装成功，加载模拟 XML 并找到网页资源。

## 交接

启动方法见 README.md。使用新业务项目时，启动绑定该工作区的服务，再连接对应的 MCP 地址。第一版面向本地单用户，直接编辑 XML 前应停止服务写入。

## v1.1 节点附件

- D4：在现有批量保存接口增加附件操作。文件按内容校验值保存在项目目录，XML 保存节点引用。节点归档和拆分保留原件。
- 19 项自动化测试通过。Chrome 验证图片、Markdown 表格与代码块、下载入口及自动刷新。
- 交付 v1.1.0 安装包和更新后的 MCP 契约、配套 Skill。

## MCP 读写与网页验收

- D5：网页提交结构化通过或退回。服务核对最新结论与当前验收范围，旧文本保留，旧通过待复核。
- D6：使用搜索摘要定位节点。MCP 按 ID 读取 Markdown 原文和图片。契约按节点类型和操作筛选。
